# Ranking de cargas

El inicio del panel muestra los diez jugadores con mayor monto de cargas acreditadas hoy, esta semana o este mes. Los períodos usan la zona horaria de Paraguay; las cargas pendientes o rechazadas no cuentan.

Antes de publicar el panel, aplicar `supabase/migrations/030_deposit_leaderboard.sql` en el proyecto Supabase. Se puede aplicar desde SQL Editor o con `npx supabase db push` si el proyecto está vinculado.
